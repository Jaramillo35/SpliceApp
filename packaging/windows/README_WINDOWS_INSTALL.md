# Windows Install Guide (Local Use)

## 1. Prerequisites

- Windows 10/11
- Python 3.10 or newer installed from python.org

## 2. Install

1. Extract the Windows bundle zip to a local folder.
2. Open the extracted folder.
3. Double-click `packaging/windows/install_windows.bat`.
4. Wait for dependency installation to finish.

## 3. Run (Local only)

1. Double-click `packaging/windows/run_streamlit_local.bat`.
2. Open `http://127.0.0.1:8501` in a browser on the same PC.

The run script binds to `127.0.0.1`, so the app is available only on that computer.

## 4. Stop

Press `Ctrl+C` in the console window running Streamlit.
